# Ejercicios: Árboles AVL (lápiz y papel)

Resolver los siguientes ejercicios **sin usar computadora**. Para cada inserción:

1. Mostrar el árbol resultante.
2. Calcular el factor de equilibrio (FE) de cada nodo.
3. Si el árbol está desbalanceado, identificar el tipo de rotación (RSD, RSI, RID, RDI) y sobre qué nodo se aplica.
4. Mostrar el árbol después de aplicar la rotación.

---

## 1. Rotaciones simples a derecha (RSD)

Insertar en un AVL inicialmente vacío la siguiente secuencia:

`30, 20, 10, 25, 5, 15, 35, 28, 27, 26`

---

## 2. Rotaciones simples a izquierda (RSI)

Insertar en un AVL inicialmente vacío la siguiente secuencia:

`10, 20, 30, 15, 40, 25, 5, 50, 55, 45, 60, 70`

---

## 3. Rotaciones dobles izquierda-derecha (RID)

Insertar en un AVL inicialmente vacío la siguiente secuencia:

`50, 20, 80, 10, 60, 90, 30, 25, 35, 28`

---

## 4. Rotaciones dobles derecha-izquierda (RDI)

Insertar en un AVL inicialmente vacío la siguiente secuencia:

`20, 60, 10, 50, 70, 80, 45, 65, 55, 48, 47, 46`
